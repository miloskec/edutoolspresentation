EduToolsFactory – Full Feature Overview

EduToolsFactory is an assessment and survey intelligence platform designed for educators, trainers and HR teams who need precise, data-driven tests and surveys – not just quick quizzes. Below is a complete overview of what the platform can do today.

1. MCQ Engine – Structured, High-Quality Questions

1.1 Manual MCQ builder

  • Create Multiple-Choice Questions (MCQs) directly in the browser.
  • Rich text question editor (formatted text, emphasis, links, lists).
  • Support for math expressions (e.g. LaTeX-style inline formulas).
  • Attach images to questions or explanations.
  • Each MCQ has a fixed, structured format: question body, four options (one correct answer and three distractors), explanation, "why others are wrong", references.

1.2 Full lifecycle for MCQs

  • Edit any part of the MCQ object at any time.
  • Duplicate existing MCQs to create variants quickly.
  • Delete MCQs that are no longer needed.
  • Reorder questions within a test using ordering fields or drag-and-drop.
  • Reuse MCQs across multiple tests and programs.

2. Survey Engine – Flexible, Scored Questionnaires

2.1 Supported survey question types

  • Single choice
  • Multiple choice
  • Text (open-ended answers)
  • Scale / Likert (e.g. 1–5 or 1–10)

2.2 Flexible scoring, dimensions and legends

Each survey question can have its own scoring model. Answer options may contribute weighted scores to one or more dimensions (subscales), including reverse-scored items and control questions.

The engine can compute a total score for the whole questionnaire and separate scores per dimension (e.g. stress & coping styles, engagement factors, personality-like profiles). Both total and per-dimension scores can be mapped to interpretation bands (legends), for example:

  • 0–10: "Needs support"
  • 11–20: "Developing"
  • 21–30: "Advanced"

This enables profile-style summaries suitable for attitude surveys, readiness checks, team snapshots and HR screening, while remaining in a non-clinical "light" mode intended for self-reflection, organizational insight and research (not for medical diagnosis).

2.3 Unlimited options for complex inventories

Unlike MCQs (which are intentionally constrained to four options), survey questions can have an unlimited number of answer options.

Combined with dimension-based scoring, this makes the engine suitable for complex questionnaires, detailed feedback instruments and multi-facet inventories – for example, multiple behaviors, coping strategies or engagement factors captured within a single item.

These richer item formats still operate in a non-clinical, insight-focused “light” mode, designed for self-reflection, organizational insight and research, rather than medical diagnosis.

3. Content Sources – From Manual Entry to Full Auto-Generation

3.1 Manual content creation

  • Hand-craft MCQs one by one.
  • Build structured survey templates for recurring use.
  • Maintain curated question banks for specific topics or courses.

3.2 Import from JSON

  • Import large MCQ sets from a local .json file in a predefined format.
  • Validate structure before import.
  • Automatically store the import path and trigger the process immediately.
  • After import, every question remains fully editable.

3.3 Auto-generate MCQ sets from URLs (AI-assisted)

  • Provide a URL as source content.
  • The system fetches the page, converts content to clean markdown, and slices it into meaningful sections with anchors.
  • AI generates full MCQ sets including questions, answers, distractors, explanations, "why others are wrong", references.
  • Generated MCQs are stored in your account and can be reviewed, edited and reordered before publishing.

4. Chrome Extension – Build Tests From the Web

4.1 Draft tests directly from the browser

  • Create and name tests in the extension popup.
  • Use extension storage to keep multiple drafts with their own list of URLs.
  • Add the current page to the active test with a single click.
  • Use the context menu (right-click) to add any link to the active test.
  • Manage multiple draft tests in parallel.

4.2 Send drafts to EduToolsFactory

When a draft is ready, send it to your EduToolsFactory account via the remote API. The server can store URLs for later processing or automatically trigger MCQ generation from those URLs (auto-mode).

The extension never sells data and uses permissions strictly to read the current tab URL or right-clicked link, store configuration and drafts, and communicate with the EduToolsFactory API.

4.3 Secure by design

  • Uses a dedicated remote token stored only in the browser’s extension storage.
  • Only sends URLs and minimal metadata that you explicitly choose.

5. Test & Survey Management

5.1 Test management

  • Create named tests within your EduToolsFactory account.
  • Attach one or more source URLs to each test.
  • Track per URL how many unique MCQs were imported and how many are published.
  • Preview and manage the full list of MCQs within each test.
  • Reuse, reorder and refine questions before making the test live.

5.2 Survey management

  • Create and name surveys for training, feedback, onboarding or HR use cases.
  • Add any combination of single choice, multiple choice, text and scale questions.
  • Configure scoring and create an interpretation legend for the final score.
  • Assign surveys just like tests: to individuals or to anonymous groups.

6. Assignment & Delivery Modes

6.1 Assign to individuals or groups

  • Assign a test or survey to a single user with results linked to that person.
  • Assign to a group with responses collected anonymously, ideal for climate surveys and feedback.

6.2 Per-session test integrity

Each landing on a test or survey link creates a new session. Sessions track progress (open, started, completed), maintain integrity of attempts, and separate runs even for the same user.

6.3 Exam vs Learning modes (for MCQs)

Exam Mode: Timed, no answers shown until completion, designed for formal assessments.

Learning Mode: Instant feedback, explanations displayed immediately, encourages iterative learning.

7. Analytics & Insights

7.1 MCQ analytics

  • Per-test overview of open, started, and completed sessions.
  • Average scores and distributions.
  • Per-question analytics: correct vs incorrect rates, popular distractors, domains that need attention.

7.2 Survey analytics

  • Visual summary of answer distributions for each question.
  • Aggregated score per respondent or segment.
  • Interpretation via legends (e.g. "Needs coaching", "On track", "High performer").
  • Perfect for HR, L&D and continuous improvement loops.

8. Remote API & Integrations

8.1 Remote Tests API

  • Token-secured endpoints for listing tests and their URLs.
  • Create tests with URLs from external systems.
  • Update tests with additional URLs.
  • Delete tests or individual URLs.
  • Response format designed for dashboards and automations.

8.2 Remote Surveys API

  • Endpoints to list surveys and their structure.
  • Inspect survey questions and options.
  • Retrieve assignments and response counts.
  • Ideal for integrating surveys into HR or learning ecosystems.

9. Security & Data Protection (High-Level)

9.1 Infrastructure and access

  • Hosted in the EU, behind a secure edge proxy.
  • All external access goes through HTTPS.
  • No direct exposure of internal containers to the public internet.
  • Only administrators can create/manage tests and surveys, assign assessments, and access detailed analytics.

9.2 Application protection

  • Multiple firewall layers protecting incoming traffic.
  • Application-level protections against common injection and abuse patterns.
  • Per-user and per-IP rate limiting for remote endpoints.
  • Logging and monitoring for security events and anomalies.

9.3 Data handling and privacy

  • Supports GDPR-aware data handling: export and deletion on request.
  • Data retained only as long as necessary or until deletion is requested.
  • Institutions act as Data Controllers; EduToolsFactory processes data strictly for assessment purposes.

10. For Teams, Educators, HR & Research Professionals

EduToolsFactory is designed for a wide range of professionals who rely on high-quality assessments, structured surveys and evidence-based insights.

For educators

  • Build precise, well-structured MCQs with full control over question quality.
  • Support learning analytics and feedback loops that guide student progress.
  • Use AI-assisted generation to create exam-ready materials in minutes.

For trainers and learning organizations

  • Create repeatable, scalable testing programs for workshops, onboarding and certification.
  • Measure knowledge retention and identify training gaps across teams.
  • Deliver assessments in either exam mode or learning mode depending on the context.

For HR and L&D teams

  • Build structured assessments and behavioral surveys with scoring systems and interpretive legends.
  • Evaluate candidates, measure team pulse, collect feedback and track development over time.
  • Combine MCQs and surveys within one cohesive analytics dashboard.

For pollsters, analysts and research institutions

  • Conduct public-opinion surveys, sentiment research, market questionnaires or internal evaluations.
  • Use unlimited-option survey questions, flexible scoring and legend mapping to model outcomes.
  • Collect anonymous responses at scale or segment results by groups when attribution is needed.
  • Generate clean data exports suitable for statistical analysis, dashboards or BI tools.

EduToolsFactory brings MCQs, surveys, analytics, AI generation, structured delivery and secure data handling into a single, coherent platform - built for educators, trainers, HR teams and research professionals alike.
