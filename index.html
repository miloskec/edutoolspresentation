Two modes: Exam and Learning.

Exam Mode

  • Timed, strict start/finish windows.
  • No answers shown until submission.
  • Hard attempts for official certifications.
  • Secure proctor-ready delivery.

Learning Mode

  • Instant feedback after each question.
  • Explains correct & incorrect options.
  • Iterative attempts to improve mastery.
  • Perfect for coaching and L&D.

Fine-tune every test before you publish.

  • Assign tests to individuals for personalized result tracking, or to groups for fully anonymous submissions.
  • Edit any generated question: tweak wording, change the correct key, or adjust distractors.
  • Add or refine explanations and “why others are wrong” for deeper learning.
  • Attach references (anchors, TOC sections, URLs) so students can jump back to the source material.

Turn any web page into a test.

  • Use the EduToolsFactory Chrome extension to capture URLs with one click.
  • Build draft tests from multiple pages, articles or documentation links.
  • Send the draft to your EduToolsFactory account and generate MCQs from the URLs.

Extension workflow (teaser)

1. Open a page or link you want to turn into questions.
2. Click "Add page to active test" in the extension popup or context menu.
3. When you're ready, send the draft to EduToolsFactory and generate MCQs.

The extension stores only your test drafts and remote token, used solely to send URLs to your EduToolsFactory account.
