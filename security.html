Trust & resilience

Security & Compliance

Defense-in-depth architecture, ready for schools, enterprises and investors.

EduToolsFactory has been designed from day one with a multi-layer security approach.
From the public internet, through an edge security layer, EU-based servers and a private container network, all the way down to application firewalls and throttling, every component is protected by its own security layer. During design and development we follow best practices inspired by PCI DSS and OWASP (OWASP Top 10 / OWASP ASVS), with a strong focus on data protection and assessment integrity.

Four pillars of protection

Network & Edge Security

  • All incoming traffic passes through a dedicated edge security layer operated by a global network provider.
  • This layer provides global routing, DDoS resistance and initial filtering of suspicious web requests.
  • Origin servers are shielded behind this edge, so external clients never see real server IP addresses.
  • Additional firewall rules, rate limiting and zero-trust access can be enabled without altering the core architecture.

Hardened EU Infrastructure

  • Hosted on servers located in the European Union, aligned with GDPR data residency expectations.
  • Only necessary ports are reachable: HTTPS, an HTTP redirect endpoint, and a restricted administrative channel.
  • A system-level firewall enforces these rules and blocks all other inbound connections.
  • OS hardening and minimal background services keep the attack surface tiny.

Private Container Network & Firewall

  • Application components run in a private container network with no public exposure.
  • All HTTP(S) traffic passes through a network gateway and firewall before reaching the app.
  • Service-to-service communication uses secure connections over the private network.
  • Container isolation and least-privilege configuration limit the blast radius of any issue.

Application-Level Protection & GDPR

  • Firewall rules and throttling protect APIs and workflows from abuse.
  • Role-based access control ensures only authorized admins can manage tests, groups, and AI generation.
  • Each assessment link is tied to a dedicated, isolated session to preserve exam integrity.
  • GDPR-aware lifecycle: exports and deletions on request, data retained only as long as required.

The current architecture already meets the expectations of modern educational and HR environments, with a clear upgrade path to full enterprise security in just a few clicks.
